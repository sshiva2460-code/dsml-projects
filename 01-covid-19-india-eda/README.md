# COVID-19 India Data Analysis

## Project Overview

This project explores COVID-19 data across Indian states and union territories using Python. It focuses on data cleaning, exploratory data analysis (EDA), and visualization of the spread of COVID-19 during the early months of 2020.

## Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Project Workflow

* Data loading and inspection
* Data cleaning and preprocessing
* Handling missing and invalid values
* State-wise confirmed cases and deaths analysis
* Daily COVID-19 case trend analysis
* Pie chart, correlation heatmap, and scatter plot visualizations
* Written summary of findings

## Files

* `covid_india_eda.ipynb` — Jupyter Notebook containing the analysis
* `cleaned_covid_india.csv` — Cleaned dataset

## Dataset Period

January 30, 2020 – August 6, 2020

## Disclaimer

This project is for educational and analytical purposes. Findings are limited to the dataset and its reporting quality.
